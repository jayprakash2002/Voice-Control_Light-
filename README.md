1. HC-05 Bluetooth Module Connections
HC-05 Pin	Arduino UNO Pin
VCC	5V
GND	GND
TXD	Digital Pin 2
RXD	Digital Pin 3 (through voltage divider)

2. Relay Module Connections
Relay Pin	Arduino UNO Pin
VCC	5V
GND	GND
IN	Digital Pin 13

3. Bulb Connections
Relay Terminal	Connection
COM	Bulb supply circuit common line
NO	Bulb switched line
Bulb	Suitable power supply
